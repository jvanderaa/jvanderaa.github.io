# ChatGPT Dots post teaser

`chatgpt-dots-teaser.mp4` is a 19.3-second, silent, captioned landscape teaser.
It uses H.264, 1280 × 720, 30 fps, and a web-optimized MP4 container.

- `poster.jpg`: opening frame for a thumbnail.
- `storyboard.jpg`: four-panel overview for review.
- `build_teaser.py`: reproducible source; requires Python with Pillow, FFmpeg,
  and the macOS Arial fonts. Run it from any directory to rebuild the assets.

The specialist-team card describes a desired feature, not an available Dots
feature. Source images are read from the blog post's bundle without alteration.
Both mentions of the colleague's name are blurred in the video and storyboard,
including during transitions. The blog screenshots are unchanged.
Nothing has been uploaded or posted to X.
